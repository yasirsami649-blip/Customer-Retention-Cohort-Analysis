# Customer Retention & Cohort Analysis
| Power BI

Power BI dashboard analyzing customer retention, repeat purchases, cohort behavior, customer acquisition, churn, and purchase forecasting.

## Key Features

- Total and repeat customer analysis
- Repeat Purchase Rate
- Customer Retention & Cohort Analysis
- New Customer Acquisition Trend
- Churned Customers by Product
- Decomposition Tree Analysis
- Customer Purchase Forecasting
- Interactive filtering

## Tools Used

- Power BI
- DAX
- Data Modeling
- Data Visualization

## Project File

The Power BI dashboard is included in this repository as a `.pbix` file.
